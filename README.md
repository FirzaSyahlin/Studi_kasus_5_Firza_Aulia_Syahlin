Program digunakan untuk menghitung biaya kamar hotel sesuai jenis kamar dan durasi menginap.
Function "hitung_hotel()" digunakan untuk menghitung total biaya. Di dalamnya ada "if" dan "elif" untuk menentukan harga kamar Standard atau Deluxe.
"tarif * durasi_menginap" digunakan untuk mendapatkan total biaya, lalu "return total" mengembalikan hasil perhitungannya.
Bagian "input()" digunakan untuk memasukkan jenis kamar, tanggal check-in, dan check-out. Setelah itu, durasi menginap dihitung dari selisih tanggal check-out dengan check-in.
Dan "print()" digunakan untuk menampilkan data pemesanan dan total biaya hotel.
